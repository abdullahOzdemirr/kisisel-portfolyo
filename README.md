# 🚀 Kişisel Portföy ve Proje Arşivi

Modern web teknolojileri kullanılarak geliştirilmiş, kişisel projelerimi, teknik yazılarımı ve kariyer yolculuğumu sergilediğim kişisel portföy ve blog web sitesi.

---

## 🛠️ Kullanılan Teknolojiler

Bu projede güncel ve performans odaklı şu teknolojiler tercih edilmiştir:
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Dil:** [TypeScript](https://www.typescriptlang.org/)
- **Stil / Tasarım:** [Tailwind CSS](https://tailwindcss.com/) / PostCSS
- **İçerik Yönetimi:** Markdown tabanlı proje ve makale yönetimi

---

## ⚙️ Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Projeyi Klonlayın:**
```bash
git clone 
cd kisisel-portfolyo

2. **Bağımlılıkları Yükleyin:**
npm install

3. **Geliştirme Sunucusunu Başlatın:**
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev

4. **Tarayıcınızda Açın:**
Tarayıcınızdan http://localhost:3000 adresine giderek projeyi görüntüleyebilirsiniz.

---

Sayfayı düzenlemeye `app/page.tsx` dosyasını değiştirerek başlayabilirsiniz. Dosyada değişiklik yaptıkça sayfa otomatik olarak güncellenir.
